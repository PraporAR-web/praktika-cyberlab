О ЛАБОРАТОРИИ

Твоя учебная среда.

300 заданий: 100 по Python, 100 по C++ и 100 по HTML. В каждом треке 10 тематических модулей. Каталог поддерживает поиск, фильтры и просмотр по 10 заданий.

Выбери время и трек — получишь один следующий блок. Начатый блок имеет приоритет. Освоенные блоки исключаются из рекомендаций; повторение доступно вручную.

Курс Python для начинающих на Stepik учтён как пройденный. Отдельные темы не отмечены освоенными без твоего подтверждения. C++ начинается с основ, опыт HTML пока не подтверждён.

Python и C++ запускаются на твоём компьютере: здесь проверяется вставленный вывод, а не выполнение кода. HTML проверяется по структуре и показывается в изолированном предпросмотре.

Прогресс хранится в этом браузере. Для другого устройства используй экспорт и импорт во вкладке «Мой прогресс». Очистка данных браузера удаляет локальный прогресс.
