# PRAKTIKA — Cyber Lab

300 практических заданий: Python, C++ и HTML.

Статический сайт. Прогресс сохраняется в браузере; есть экспорт и импорт. Python и C++ запускаются локально, приложение проверяет вставленный вывод. HTML проверяется в браузере.

План развития: [ROADMAP.md](ROADMAP.md). Для интерактивных флажков перенесите содержимое плана в GitHub Issue.

Публикация: Settings → Pages → Deploy from a branch → main → / (root) → Save. Перед этим выберите подходящую видимость репозитория.

Перед переходом с другого адреса экспортируйте прогресс там и импортируйте на новой странице.
