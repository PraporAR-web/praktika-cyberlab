# PRAKTIKA — Cyber Lab

**[Открыть приложение](https://praporar-web.github.io/praktika-cyberlab/)** · **[План развития с галочками](https://github.com/PraporAR-web/praktika-cyberlab/issues/1)**

300 практических заданий: по 100 для Python, C++ и HTML. В каждом треке 10 тематических модулей, поиск и фильтры.

Выбери 5, 15, 30 или 45 минут. Приложение предложит следующий блок с целью, подсказками и критерием завершения. Начатое можно продолжить позже, освоенное не повторяется автоматически. Жёстких дедлайнов нет.

## Прогресс

Отметки и черновики сохраняются в этом браузере. Для другого устройства используй экспорт и импорт во вкладке «Мой прогресс».

При переходе со старого адреса Sites сначала экспортируй прогресс там, затем импортируй на GitHub Pages. Данные автоматически между адресами не переносятся. Закрытая версия Sites остаётся доступной.

## Проверка заданий

Python и C++ запускаются на твоём компьютере: приложение сравнивает вставленный вывод, а не исполняет код. HTML проверяется по структуре и показывается в изолированном предпросмотре.

## План развития

Постоянный интерактивный чек-лист: [Issue #1](https://github.com/PraporAR-web/praktika-cyberlab/issues/1). Владелец репозитория может ставить и снимать галочки прямо в описании задачи. Снимок плана также находится в [ROADMAP.md](ROADMAP.md).

## Публикация

Статический сайт публикуется GitHub Pages из ветки main, корень репозитория. Сборка не требуется; .nojekyll отключает преобразование содержимого Jekyll.
