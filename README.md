# PRAKTIKA — Cyber Lab

**[Открыть приложение](https://praporar-web.github.io/praktika-cyberlab/)** · **[План развития с галочками](https://github.com/PraporAR-web/praktika-cyberlab/issues/1)**

300 практических заданий: по 100 для Python, C++ и HTML. В каждом треке 10 тематических модулей, поиск и фильтры.

Выбери 5, 15, 30 или 45 минут. Приложение предложит следующий блок с целью, подсказками и критерием завершения. Начатое можно продолжить позже, освоенное не повторяется автоматически. Жёстких дедлайнов нет.

## Прогресс

Отметки и черновики сохраняются в IndexedDB этого браузера. Прежнее сохранение localStorage и экспорты v1 автоматически преобразуются в схему v2 с теми же ID заданий. Исходное сохранение v1 не удаляется и не перезаписывается. Небольшие настройки дополнительно записываются в localStorage.

Перед импортом приложение показывает количество освоенных блоков и черновиков; замена выполняется только по явному нажатию. Текущая версия и отличающаяся локальная сессия сохраняются вместе с заменой в одной транзакции. В разделе «Резервные копии» доступны 5 последних копий: скачивание и восстановление с дополнительной копией перед откатом. Повреждённые файлы не импортируются частично; исходные повреждённые данные можно скачать.

Изменения разных полей из нескольких вкладок объединяются. При конфликте одного поля сохранение приостанавливается: можно скачать локальную сессию или загрузить общую версию, сохранив локальные различия в копии. Ошибки квоты и доступа отображаются явно; до успешной записи статус «сохранено» не показывается.

Для другого устройства используй экспорт и импорт во вкладке «Мой прогресс». Автоматической облачной синхронизации нет. Очистка данных браузера удаляет и прогресс, и локальные копии, поэтому для независимой копии скачивай экспорт.

При переходе со старого адреса Sites сначала экспортируй прогресс там, затем импортируй на GitHub Pages. Данные автоматически между адресами не переносятся. Закрытая версия Sites остаётся доступной.

## Проверка заданий

Python и C++ запускаются на твоём компьютере: приложение сравнивает вставленный вывод, а не исполняет код. HTML проверяется по структуре и показывается в изолированном предпросмотре.

## План развития

Постоянный интерактивный чек-лист: [Issue #1](https://github.com/PraporAR-web/praktika-cyberlab/issues/1). Владелец репозитория может ставить и снимать галочки прямо в описании задачи. Снимок плана также находится в [ROADMAP.md](ROADMAP.md).

## Публикация

Статический сайт публикуется GitHub Pages из ветки main, корень репозитория. Сборка не требуется; .nojekyll отключает преобразование содержимого Jekyll.

## Проверки

Нужен Node.js 22 или новее. `npm ci` устанавливает единственную тестовую зависимость — fake-indexeddb; для работы сайта зависимости не нужны.

- `npm test` — 25 тестов сохранений, миграции, квоты, резервных копий и конкурентных изменений на IndexedDB-транзакциях.
- `npm run check` — проверка синтаксиса JavaScript.

В браузере проверены миграция, сохранение после перезагрузки, импорт и восстановление, конфликт двух вкладок; окно восстановления проверено на мобильной ширине 390 px.
